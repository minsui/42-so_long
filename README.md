# so_long

## Description

`so_long`은 학교 그래픽 라이브러리인 **MiniLibX**로 만든 작은 2D 탑다운(top-down) 게임입니다. 플레이어는 맵에 배치된 모든 수집 아이템을 모은 뒤, 최소한의 이동 횟수로 출구에 도달해야 합니다.

맵은 `.ber` 확장자를 가진 텍스트 파일로부터 불러오며, 다음 5가지 문자로 구성됩니다.

| 문자 | 의미 |
|------|------|
| `1`  | 벽 |
| `0`  | 빈 공간 |
| `C`  | 수집 아이템 |
| `E`  | 출구 |
| `P`  | 플레이어 시작 위치 |

게임이 시작되기 전, 맵은 다음 기준으로 전부 검증됩니다: 직사각형 형태여야 하고, 벽으로 완전히 둘러싸여야 하며, 플레이어 시작 위치와 출구가 정확히 1개씩 있어야 하고, 수집 아이템이 최소 1개 있어야 하며, 플레이어가 모든 수집 아이템과 출구까지 실제로 도달할 수 있는 경로가 있어야 합니다(flood fill 방식으로 검사). 이 중 하나라도 실패하면 프로그램은 `Error`와 구체적인 에러 메시지를 출력하고 깨끗하게 종료됩니다.

맵이 유효하면 MiniLibX 이미지로 렌더링된 맵이 담긴 창이 열립니다. 플레이어는 `W`, `A`, `S`, `D` 키로 이동하며, 이동할 때마다 셸에 이동 횟수가 출력되고, 모든 수집 아이템을 모은 뒤 출구에 도달하면 게임이 종료됩니다.

## Instructions

### 요구 사항

- MiniLibX 의존 라이브러리(`libx11-dev`, `libxext-dev`)가 설치된 Linux 환경
- `make`와 `cc`

### 빌드

```bash
make
```

위 명령은 `libft`, MiniLibX, 그리고 프로젝트 소스 파일들을 컴파일하여 `so_long` 실행 파일을 만듭니다. 변경된 내용이 없으면 다시 `make`를 실행해도 불필요한 재링크는 일어나지 않습니다.

### 실행

```bash
./so_long maps/map.ber
```

`maps/map.ber` 부분은 원하는 유효한 `.ber` 맵 파일 경로로 바꿔서 실행하면 됩니다.

### 조작 방법

| 키 | 동작 |
|----|------|
| `W` `A` `S` `D` | 상/좌/하/우 이동 |
| `ESC` | 종료 |
| 창 닫기 버튼 | 종료 |

### 정리

```bash
make clean   # 오브젝트 파일 삭제
make fclean  # 오브젝트 파일과 실행 파일 삭제
make re      # fclean 후 다시 빌드
```
